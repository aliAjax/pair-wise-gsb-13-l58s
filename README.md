# 加油站班次交接（按价格段拆账）

班中调价后，不再只记整班均价：一个班次可登记多个油品价格段，逐段记录起止泵码与单价，
泵码逐段衔接；现金、电子支付对照各段应收计算长短款，写明原因后送站长复核；
复核通过整班冻结为只读凭证，再次打开只能带原因订正并永久保留旧金额与时间。

- 技术栈：Vue 3 + Vite + TypeScript，**无额外运行时依赖**（未引入 UI 库/状态库）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 规则自测：`npm run verify-rules`（29 项，覆盖拆账汇总、泵码衔接、送审拦截、冻结、订正留痕与驳回恢复）
- 数据：全部保存在浏览器 `localStorage`（key：`gas-station-shift-vouchers-v1`，带版本号），含两条演示数据，可在“油站与油品设置”里一键恢复

## 分层结构（页面交互 / 规则 / 本地存储分开）

| 文件 | 职责 |
| --- | --- |
| `src/types.ts` | 数据模型：班次、价格段、汇总、订正留痕、时间线 |
| `src/rules.ts` | **纯业务规则**，不碰 DOM 与存储：走字/应收计算、泵码衔接校验、长短款、`canSubmit` 送审条件、送审/通过/驳回、冻结快照、订正比对与驳回恢复、凭证号生成 |
| `src/storage.ts` | **本地存储**：`localStorage` 读写、版本迁移、演示种子数据 |
| `src/components/ShiftList.vue` | 班次列表与状态筛选 |
| `src/components/ShiftEditor.vue` | **页面交互**：价格段录入、实时汇总、待修正提示、送复核/驳回/冻结/订正的界面编排 |
| `src/App.vue` | 角色切换（营业员/站长）、规则函数与存储的编排、油站设置 |
| `scripts/verify-rules.ts` | 规则层自测（esbuild 转译后由 node 执行） |

## 业务规则

1. **价格段拆账**：每段选油品、填起始泵码 / 结束泵码 / 单价；走字 = 止码 − 起码，段应收 = 走字 × 单价。
   班中调价一次就新增一段，同一油品按录入顺序逐段衔接。
2. **泵码衔接**：同油品第一段起码必须等于接班起泵码，其后每段起码必须等于上段止码；
   接不上的段落标黄提示，整班留在“待修正”，不允许送站长复核。
3. **汇总与长短款**：逐段应收 → 按油品汇总 → 应收合计；实收 = 现金 + 电子支付；长短款 = 实收 − 应收。
   长短款不为 0 时**必须填写原因**，否则不能送复核。
4. **站长复核**：站长角色可“复核通过”或“驳回（必填原因）”。通过后整班冻结，
   生成凭证号（`PZ-YYYYMMDD-序号`）并保存冻结快照；驳回退回营业员修改后重新送审。
5. **冻结凭证订正**：已冻结班次为只读；只能点“带原因订正”，填写原因后修改，
   系统逐字段比对生成变更明细，并记录订正前的旧应收/旧现金/旧电子支付及时间；
   订正重新进入复核流程，通过后重新冻结；被驳回则按冻结快照恢复只读凭证与旧金额。
6. 只读凭证支持打印（打印样式仅输出凭证内容）。
